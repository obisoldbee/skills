# MiniMax H3 Prompt

作为 MiniMax H3 提示词工作的唯一入口：先确定素材路线和输出目标，再按需采用一个官方创意方向，最后输出一份连贯结果。本 Skill 只准备、审查和改写提示词；不登录账号、不上传素材、不消耗额度、不提交生成任务，也不声称已经生成成功。

输入：用户需求、实际提供的素材、可选的既有提示词，以及已经可靠读取的文件属性。

任务：选择 H3 模式和输出面，映射素材角色，按需选择一个创意方向，编写或修订提示词，并指出会阻止后续提交的未知与冲突。

约束：不猜素材事实，不把上游风格 Skill 当成当前环境可执行工具，不把案例愿望写成能力保证，不执行账号或生成操作。

输出格式：路由、素材角色、提示词、参数与约束、下一步。默认只给一种最终提示词格式，不同时堆叠网页版和结构化版。

成功标准：路线、输出面和素材用途一致；编号可追溯；结构符合所选目标；未知项原样保留；用户可以直接复制或继续交给获授权执行流程。

语言：说明文字跟随用户。网页人工复制提示词默认跟随用户；结构化 H3 字段主体使用英文，台词、歌词和画面文字保留原语言。

## 先确认边界

- 只有用户明确指向 MiniMax H3、海螺 H3、Hailuo H3，或明确点名本 Skill 所列的 MiniMax H3 官方流程时才使用。不要因孤立出现 `H3` 自动触发。
- 先盘点用户实际提供的素材。文件名、缩略图和用户描述不能证明分辨率、时长、编码、大小或授权状态；未读到的值写 `Unknown`。
- 本 Skill 的输入数值来自 2026-09-02 飞书手册快照；官方开源 Skill 路由来自 2026-09-02 固定的上游提交。真实提交前如当前界面或 API 已变化，以当前平台为准。
- 官方 `h3-prompt-writing` 可移植到通用 Agent；另外八个风格 Skill 依赖 MiniMax Hub 专用画布和工具。在非 Hub 环境中只能提炼其创意目标、输入、分镜和验收重点，不能宣称已执行完整工作流。
- 把“锁脸”“锁动作”“保持不变”视为控制目标，不承诺精确复刻、逐像素不变、文字零错误或口型必然同步。

## 执行流程

### 1. 盘点素材

逐项记录：`@素材编号`、类型、已核实属性、用户指定用途。保留用户编号；没有实际素材时不要杜撰素材编号。

需要完整输入限制时读取 [references/inputs-and-routing.md](references/inputs-and-routing.md)。至少检查：时长、数量、混合素材总数、格式、单文件大小、按入口适用的图片/视频尺寸与比例、提示词长度。音频不能单独作为全能参考输入。

### 2. 选择 H3 模式

按素材语义而不是文件数量判断。混合参考优先于关键帧 Base 模式：

1. 有现成视频并要求替换、增加、删除或局部修改：`Ref2VA / 全能参考（视频编辑）`。
2. 关键帧之外还存在人物、场景、物体、风格、构图、视频、音频或其他参考角色：`Ref2VA / 全能参考`；关键帧关系写入 Ref2VA，不降为 Base。
3. 没有素材：`T2VA / 文生视频`。
4. 全部引用恰好只有一张明确首帧：`I2VA / 首帧`。
5. 全部引用恰好只有一张明确尾帧：`L2VA / 尾帧`。
6. 全部引用恰好只有两张明确起点和终点：`FL2VA / 首尾帧`。

两张“人物图 + 风格图”不是首尾帧。只有音频、混合素材超过 12 个或其他硬约束冲突时标记 `Blocked`，指出冲突并请用户选择；不要擅自丢弃素材。

关键示例：

- 无素材、目标是 H3-Base API → `T2VA + H3 结构化`。
- 只有一张明确尾帧、目标是海螺网页 → `L2VA + Web / App 人工复制`。
- 人物图加风格图 → `Ref2VA`，不是 FL2VA。
- 首帧加配乐或首尾帧加额外风格参考 → `Ref2VA`，保留关键帧关系和其他参考角色。

### 3. 选择输出面

只选择一种：

- `Web / App 人工复制`：用户准备粘贴到海螺网页或 App，或没有要求 API、H3-Base、Context-IR、固定字段。使用本包的网页三段式。
- `H3 结构化`：用户明确要求 API、本地 H3-Base、H3-Context-IR、结构化字段，点名官方 `h3-prompt-writing`，或直接使用 `T2VA`、`I2VA`、`FL2VA`、`L2VA`、`Ref2VA` 这些标准模式代码且没有另行指定网页/App。使用官方字段顺序。

用户没有说明时，根据明确的使用场景选择；场景也未知且两种结果会明显不同，先问一个最小问题。不要为了显得完整而同时输出两套长提示词。

结构化 Base 模式（T2VA / I2VA / FL2VA / L2VA）依次使用：

1. `integrated_multimodal_description`
2. `overall_soundscape`
3. `non_diegetic_music`

结构化 Ref2VA 依次使用：

1. `subject_definitions`
2. `summary`
3. `retention_analysis`
4. `detailed_description`
5. `overall_soundscape`
6. `non_diegetic_music`

字段含义、标签规则和两种输出面的写法见 [references/prompt-workflow.md](references/prompt-workflow.md)。

需要官方精确结构时，将本 `SKILL.md` 所在目录记为 `<skill-root>`，运行只读解析器：

```bash
python3 <skill-root>/scripts/resolve_official_skills.py --route h3-base
python3 <skill-root>/scripts/resolve_official_skills.py --route h3-ref
```

解析器只接受经过核验的官方 remote、分支、上游、clean 状态和已审查 HEAD，并返回本次应读取的官方文件。`status=available` 时只读取返回的 `files`；`status=unavailable` 时使用本包的冻结适配摘要，并把结果称为“兼容结构化草案”，不要声称已经加载官方精确合同。解析失败不授权联网、安装、更新或绕过校验。

解析器合同：

- 用途：定位本机已审查的官方 `skills/` 文件，不执行其中内容。
- 适合使用：需要官方精确结构，或需要一个官方风格的完整创意与验收合同。
- 不适合使用：纯网页三段式且不需要官方风格，或用户要求上传、生成、安装、更新上游。
- 参数：`--route h3-base`、`--route h3-ref` 或一个允许的官方风格目录名。
- 返回：JSON；`status`、`reason`、核验信息和只读 `files` 列表。
- 失败处理：不重试、不联网、不更新；使用冻结摘要并明确降级，然后继续能够安全完成的提示词准备。

### 4. 按需选择一个官方创意方向

只有当用户的目标明显命中，或用户明确点名时才选择。每次最多采用一个主方向：极简产品广告、3D 动画短片、纸艺定格科普、品牌宣传片、歌词排版 MV、双人游戏开场、半调纸拼贴科普、手绘动画与真人空间融合。

先读 [references/official-skills-routing.md](references/official-skills-routing.md)。若需要保留选中方向的完整创意与验收合同，再运行：

```bash
python3 <skill-root>/scripts/resolve_official_skills.py --route <官方风格目录名>
```

`status=available` 时只读取返回的一个风格入口及其 references，提取创意 brief、镜头重点和验收清单，再回到本 Skill 的 H3 模式与输出面。跳过并禁止执行上游 Hub 画布、选择卡片、`hub_*`、生成、合成和输出动作。`status=unavailable` 时只能使用本包的高层方向摘要，不得称为完整官方流程。

若用户同时点名多个方向且最终交付目标不能决定主方向，只问一个最小选择问题，不得自行删除或静默合并用户要求。

### 5. 映射素材角色

每个拟作为输入的素材都要写清唯一或有边界的用途，例如：

- `@图片1`：人物身份与服装参考；
- `@图片2`：场景和构图参考；
- `@视频1`：动作与运镜参考；
- `@音频1`：节奏、情绪、音色或待复用音频中的一种。

网页提示词使用用户界面的 `@素材编号`。结构化提示词使用稳定的 `<Picture N>`、`<Video N>`、`<Audio N>` 和 `<Subject N>`，同一素材在所有字段中保持一致。要求复刻歌词、台词、标题、Logo 或界面文字时，必须给出逐字原文；用户未提供时保留为待补信息。

### 6. 编写提示词

- 网页人工复制：使用 `参考素材说明 + 核心创意 + 画面过程说明`。文生视频省略素材说明。
- H3 结构化 Base：按时间线写画面、动作、镜头、说话者和画内声音，再分别概括整体声景与非叙事音乐。
- H3 结构化 Ref2VA：先定义主体和引用关系，再概括目标与保留策略，最后写完整时间线、整体声景和非叙事音乐。

一镜到底写成连续过程，不使用多个 Shot；切镜时重新指明景别和角色；台词长度要适配镜头时长。不要背景音乐时写 `non_diegetic_music: N/A` 或网页提示词中的等价说明，不要误写成静音输出。

### 7. 自检并输出

检查素材编号都有角色、模式与素材含义一致、输出面符合使用目标、风格方向至多一个、要求之间无冲突、未知项没有被猜测、提示词实际字符数不超过快照上限。不要照搬案例中的 `4K/60fps`；案例目标不是能力保证。

默认使用以下紧凑结构；若 `Blocked`，省略“提示词”，只给冲突和最少解除方式：

```markdown
## 路由
- H3 模式：T2VA / I2VA / FL2VA / L2VA / Ref2VA / Blocked
- 输出面：Web / App 人工复制 / H3 结构化
- 创意方向：无 / 一个命中的官方方向
- 理由：仅依据已知素材、用途和目标环境。

## 素材角色
- @素材编号或 <Picture N> / <Video N> / <Audio N> / <Subject N>：类型；角色；已核实特征。
- Unknown：尚未核实但影响提交的属性。

## 提示词
<只输出所选格式的一份可复制提示词>

## 参数与约束
- 已指定：用户明确给出的值。
- 建议值：明确标为建议，不伪装成用户决定。
- Unknown / Conflict：未核实或冲突项。

## 下一步
- 只列阻塞提交或改变路线的最少问题；若无则说明可交给获授权执行流程。
```

完成后停止本 Skill 的准备阶段，不要自行上传、提交、反复猜测未知属性或替用户选择要删除的素材。若同一请求已经明确授权实际生成，将准备结果交给具备执行能力的流程继续；不得用本 Skill 的停止规则取消后续执行。
