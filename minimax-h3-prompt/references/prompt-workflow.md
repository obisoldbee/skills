# H3 提示词写作工作流

## 官方三段式

```text
完整提示词 = 参考素材说明 + 核心创意 + 画面过程说明
```

### 参考素材说明

只描述用户实际提供且拟作为输入的素材，并给每项素材分配清楚的角色：

```text
@图片1 作为人物身份与服装参考。
@图片2 作为夜市环境与色彩氛围参考。
@视频1 仅参考舞步和镜头推进节奏。
@音频1 作为音乐节拍参考，不复用其中人声。
```

可以使用的角色包括人物、物体、场景、首帧、尾帧、音色、故事板、风格、构图、动作、运镜、节奏、情绪、音频复用和视频编辑源。角色是控制意图，不是“锁定成功”的保证。

### 核心创意

用一句话写清：主体、地点、事件、题材或视觉风格，以及是否切镜或采用特殊运镜。

抽象词需要转换为可见动作和画面。例如不要只写“充满宿命感”，应写人物停顿、光线变化、镜头距离和环境反应。需要环绕效果时，拆成可执行的平移、摇摄和主体运动，不只写“镜头环绕”。

### 画面过程说明

多镜头任务按时间或 Shot 写：

```text
Shot 1（0–3 秒）：景别；当前主体；可见动作；镜头运动；环境声音。
Shot 2（3–7 秒）：切到哪个景别；此前哪个角色；动作与表演；逐字台词；音效。
```

- 切镜后重新指明景别和角色，减少身份与空间漂移。
- 台词与镜头时长相称；不要在 3 秒镜头塞入长段对白。
- 需要跨镜头声音时可明确 J-cut 或 L-cut，并写清画内/画外说话者。
- 一镜到底写成单段连续过程，不使用多个 Shot 标题。
- 需要画面文字、Logo、标题或 UI 时写出逐字原文，但不要保证绝不乱码。
- 不需要背景音乐时写 `非叙事性音乐：N/A`；仍可保留环境声、动作声和对白。

## 三类任务的写法差异

### 文生视频

无素材时补足外观、空间、动作和风格。可以按“大全景交代空间 → 中景承载动作 → 特写强调细节”组织，但不要为了套模板强行切镜。

### 首尾帧

先声明图片位置，再描述如何连续抵达另一端：

```text
@图片1 是首帧。镜头从该构图开始，人物……，光线逐渐……，最后自然停在……。
```

两张图时分别标明首帧和尾帧。不要把端点图重新当作人物或风格参考，也不要自行加入多场景剪辑。

### 全能参考与编辑

多来源任务只从每项素材取指定维度。编辑已有视频时：

1. 指明哪个视频是编辑源；
2. 逐条写要替换、增加、删除或局部修改的内容；
3. 写出需要尽量保留的可见要素；
4. 使用“尽量保持”“未编辑部分相对稳定”等目标描述，不承诺逐像素无损。

## 声音与多语言

- 区分节奏参考、情绪参考、音色参考和复用原音频。
- 要复刻台词、歌词或旁白时给出逐字文本；未提供文本时不要代写成用户原话。
- 多语言任务写清说话人、语言、地区或口音、逐字对白、情绪、镜头时长，以及画内/画外声音关系。
- 口型同步可以作为目标，不能写成必然结果。
- 手册把 11 种 TTS 语言描述为“精准覆盖”，把 40 多种语言描述为可衍生探索；不要把后者写成同等质量保证，也不要猜测未列出的完整语言名单。

## 冲突自检

- “使用参考音乐”与“无 BGM”冲突。
- “一镜到底”与多个切镜 Shot 冲突。
- 要人物一致却没有人物参考图，是风险而不是可保证结果。
- 要准确文字却没有逐字原文，信息不足。
- 素材编号出现于提示词但不在输入清单中，是错误。
- 提示词超过 7000 字符，应缩短而不是声称平台会接受。

若文字容易乱码，可以让用户把目标文字做成图片素材并在提示词中声明“按图片理解”，但这只降低风险，不保证准确渲染。
