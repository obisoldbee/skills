# 输入限制与路线选择

本页来自 2026-09-02 的 MiniMax H3 官方手册快照，用于提示词准备阶段的预检。它不是当前网页或 API 的实时合同；真实提交前如有疑问，以当前平台为准。

## 输出与通用限制

| 项目 | 手册快照所述 |
|---|---|
| 输出时长 | 4–15 秒 |
| 帧率 | 24 FPS |
| 声音 | 结果带原生双声道声音；“无 BGM”不等于静音 |
| 分辨率 | 768p 或手册推荐的 1440p；不要把案例里的 4K 当能力规格 |
| 提示词 | 不超过 7000 字符；应实际计数，不凭感觉声称合规 |

### 画幅

- 首尾帧：跟随输入图片原始比例。
- 文生视频：`21:9`、`16:9`、`4:3`、`1:1`、`3:4`、`9:16`。
- 全能参考：可选上述比例或自动判断。

未读取图片元数据时，不要声称首尾帧会输出某个具体比例。

## 首尾帧入口

- 可输入 0–2 张图；0 张图在手册中可进入文生，但这里把它作为创作路线而不是猜测 API endpoint。
- 图片边长：256–5760 像素。
- 图片比例：`5:2` 至 `2:5`。
- 一张图时必须明确它是首帧还是尾帧。
- 两张图必须确实是起点和终点；人物图、风格图等参考素材应走全能参考。
- 模型补全两帧之间的动作、光影和声音，不应据此承诺自动切镜。

## 全能参考入口

| 素材 | 数量 | 时长 | 尺寸与比例 | 格式 | 单文件大小 |
|---|---:|---:|---|---|---:|
| 图片 | 最多 9 张 | — | 边长 256–5760；手册未另列全能参考图片比例限制 | JPG、JPEG、PNG、WEBP、HEIC、HEIF | 30 MB |
| 视频 | 最多 3 段 | 每段 2–15 秒；总计不超过 15 秒 | 边长 256–5760；比例 `5:2` 至 `2:5` | H.264/AVC 或 H.265/HEVC；内嵌音频 AAC/MP3 | 50 MB |
| 音频 | 最多 3 段 | 每段 2–15 秒；总计不超过 15 秒 | — | WAV、MP3 | 15 MB |

- 图片、视频和音频混合后最多 12 个文件。
- 音频必须搭配图片或视频，不能单独输入。
- 手册称素材合计大小不受单一总量限制，同时又写 API 请求体上限 64 MB 并建议用 URL 传素材。二者指向不同传输边界；不要把 64 MB 误写成网页素材总大小上限，也不要声称内联请求可以无限大。
- 文件扩展名不等于已核实编码；只有实际检查后才能填写编码、时长、尺寸和大小。

## 路由表

| 已知情况 | 路线 | 注意 |
|---|---|---|
| 无素材 | 文生视频 | 具体描述人物、空间、动作和风格 |
| 1 张明确的首帧或尾帧 | 首尾帧 | 写清该图的位置 |
| 2 张明确的起点与终点 | 首尾帧 | 只写连续补间，不自动加切镜 |
| 1–2 张图，但用途是人物、场景、风格、构图等 | 全能参考 | 不要仅按数量误选首尾帧 |
| 含视频、音频或多个来源分工 | 全能参考 | 每个素材都要标用途 |
| 编辑现有视频 | 全能参考（视频编辑） | 写清修改项和保留目标 |
| 只有音频 | Blocked | 补图片或视频，或移除音频改为文生 |
| 混合素材超过 12 个 | Blocked | 请用户选择删减，不擅自丢弃 |

## 预检结论词

- `Specified`：用户明确给出，或已从文件可靠读取。
- `Proposed`：为帮助创作提出，但用户尚未确认。
- `Unknown`：当前证据不能确认。
- `Conflict`：多个要求互相冲突或违反快照约束。
- `Blocked`：没有用户选择或补充就无法形成可提交输入。

未知不等于失败。只有未知项会改变入口或阻止提交时，才向用户追问。
