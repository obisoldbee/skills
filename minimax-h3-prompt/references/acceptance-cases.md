# 触发与路由验收样例

这些样例用于检查低上下文 Agent 是否会误触发、误选入口或伪造素材事实。

| 请求 | 预期 |
|---|---|
| “为 MiniMax H3 写一个 8 秒、9:16 的雨夜追逐短片，没有素材。” | 触发；文生视频；保留 8 秒和 9:16，不杜撰素材编号 |
| “这张图是 H3 视频最后一帧，让镜头从空书桌推进到它。” | 触发；L2VA / 尾帧；明确图片是最终帧；推导合理开场并连续抵达，不自动切镜 |
| “用 H3：图 1 是首帧、图 2 是尾帧，让人物从举剑到收剑。” | 触发；首尾帧；比例取决于输入图片，未读元数据则标 Unknown |
| “两张角色图、一张街景图、一段舞蹈视频和一段音乐，做 12 秒 H3 MV。” | 触发；全能参考；逐项分配人物、场景、动作、节奏或情绪角色 |
| “只有一段旁白 MP3，直接在 H3 做视频。” | 触发但 Blocked；音频不能单独输入，要求补图/视频或改为文生 |
| “在 H3 里把视频 1 的猫换成狗，其他尽量不变。” | 触发；全能参考（视频编辑）；只写明确变更和保留目标，不承诺无损 |
| “给 H3 的两张图是人物和杂志风格，不是开头结尾。” | 触发；全能参考，不因只有两张图误选首尾帧 |
| “把这张首帧整理成 H3-Base API 可用的官方结构化提示词。” | 触发；I2VA；H3 结构化；输出对齐说明和 Base 三字段，不再附一份网页三段式 |
| “把现有视频按 H3-Context-IR 的 Ref2VA 格式改成主角换装，其他尽量保留。” | 触发；Ref2VA 视频编辑；按六字段输出并逐项说明保留边界 |
| “用海螺 H3 做一个高质感极简耳机广告，我要复制到网页。” | 触发；选择极简产品广告方向；按实际素材选择 H3 模式；输出 Web / App 三段式，不调用 Hub 工具 |
| “用 H3 做歌词排版 MV，再顺便套 3D 动画、纸拼贴和品牌宣传三个官方 Skill。” | 触发；先按最终交付目标选择一个主方向，其他仅保留明确兼容约束，不把多个完整流程堆叠 |
| “把一张首帧和一段配乐一起用于 H3。” | 触发；Ref2VA，不误选 I2VA；关键帧关系和音频参考都进入六字段 |
| “同时用纸艺定格和手绘真人两个官方方向，其他目标没定。” | 触发；只问一个最小主方向问题，不自行混合或删除用户要求 |
| “把 MiniMax 官方九个 Skill 都安装并自动生成成片。” | 本 Skill 可解释能力与兼容性，但不安装或执行；只有 h3-prompt-writing 可直接移植，八个风格流程需要 MiniMax Hub |
| “先用 H3 官方结构整理提示词，然后替我提交生成。” | 本 Skill 完成结构化准备并交给另一个已获授权的执行流程；不得用自身不上传的边界取消用户明确授权的后半段 |
| “请为 H3 检查输入并准备提示词：9 张图、3 段视频、1 段音频都要作为参考。” | 触发但 Blocked；总数 13 超过 12，请用户选择，不擅自丢弃 |
| “已核实 H3 的视频 1 是 200×200，作为动作参考。” | 触发但 Blocked；视频边长低于 256，不写成可提交输入 |
| “给 Runway Gen-4 写图生视频提示词。” | 不触发；不注入 H3 约束 |
| “H3 是路由器型号，整理维修记录。” | 不触发；孤立型号不是视频模型语境 |

## 失败判据

- 未看到实际素材就填入尺寸、时长、格式或编号；
- 把两张任意参考图一律路由到首尾帧；
- 把一张尾帧误写成 I2VA，或把首尾帧任务误写成 Ref2VA；
- 只有音频仍给出“可提交”的提示词；
- 忽略全能参考图片/视频尺寸或视频比例越界；
- 把 4K/60fps、锁脸、无损编辑或准确文字写成产品保证；
- 自动上传、提交、消费额度或声称生成成功；
- 同时输出网页三段式和完整结构化提示词，却没有用户要求两份；
- 把八个 MiniMax Hub 风格 Skill 的专用工具步骤冒充为当前环境已执行；
- 为了“融合”而复制或拼接九个上游 Skill 全文；
- 对其他模型或非视频语境的 `H3` 误触发；
- 为了显得完整而追问不影响路线或提交的细节。
