# 资料来源与能力边界

## 来源

- 官方手册：<https://vrfi1sk8a0.feishu.cn/wiki/FIWjwgL33ipnkekzk30crmKUnIh>
- 本包依据的快照日期：2026-09-02。
- 项目 wrapper 单独保存飞书“Markdown → 所有内容”导出的手册和媒体；这些大文件不属于本可发布 Skill 包。

手册写有“持续更新中”和无年份的“9/1 新增”，没有可审计的版本号。因此，输入数量、分辨率、语言覆盖和传输限制都应表述为“快照所述”。

## 发现的内部冲突

1. 规格表写 24 FPS、768p/1440p，但 MG 案例提出 4K、60fps。规格表是预检依据；案例只代表创作目标。
2. 提示词上限是 7000 字符，但手册内有一个清理 Markdown 后仍超过 7000 字符的长案例。不要把该案例原样当作合规模板。
3. 手册把文生、首尾帧、全能参考作为创作模式，但“无素材即文生”又可出现在多个入口描述中。不要据此虚构三个互斥 API endpoint 或请求字段。
4. 能力说明称未编辑内容“相对稳定”，部分案例却要求“完全不变”或“100% 不变”。后者是提示词目标，不是产品保证。
5. 手册称素材合计大小不受单一总量限制，同时限制 API 请求体 64 MB。应区分素材文件限制与内联传输限制。
6. 结果带声音与“非叙事性音乐：N/A”不冲突：后者只关闭背景音乐，不代表静音。

## 不可从手册推出的事实

- 当前账号是否有 H3 权限、额度、区域可用性或某一分辨率选项；
- 当前价格、排队时间、生成质量或提交成功；
- API 模型名字段、上传 URL 字段、异步轮询方式和错误码；
- 素材版权、肖像权、音色授权或商用资格；
- “锁脸”“锁动作”“文字原样输出”“口型同步”的确定性成功率。

若用户要求实际 API 调用或网页生成，先完成提示词与输入清单，再交给具备当前平台执行能力的流程；本 Skill 本身不处理登录、上传、付费或提交。
