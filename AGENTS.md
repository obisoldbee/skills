# OB Skills Distribution Checkout

> Agent entry point for this public distribution repository.

## Scope

This checkout distributes portable Skill packages. It is not a device's Projects Workspace, `obisoldbee-skills` Project Collection, or a mirror of local project wrappers.

## Mandatory Rules

1. Follow `project-conventions/SKILL.md` and select the lifecycle before any governance layer.
2. If the user asked only to clone/download this repository, verify `MANIFEST.sha256` and stop. Do not inspect the intended future target, old workspaces, siblings, or Agent roots.
3. If bootstrapping a Skill, operate on exactly one named Skill and one named Agent/target. Link apply requires explicit approval; after readback, stop for a fresh task.
4. If updating this checkout, allow only a clean fast-forward update plus package validation. Do not restructure, create records, scan links, or initialize another target.
5. Never interpret this checkout or its parent as the target of project initialization unless the user explicitly names it as that target.
6. Do not expose local paths, credentials, caches, private Skills, or device inventory in this public repository.

## Entry Points

| Path | Purpose |
|---|---|
| `README.md` | Human bootstrap and update workflows |
| `MANIFEST.sha256` | Published file digests |
| `scripts/verify_release.py` | Offline manifest and portability validation |
| `scripts/link-macos.sh` | Scoped macOS/Linux Skill link scan/apply |
| `scripts/link-windows.ps1` | Scoped Windows junction scan/apply |
| `project-conventions/SKILL.md` | Lifecycle and filesystem-governance rules |

## Update-only stop boundary

After reporting the before/after commit and successful validation, stop. Do not edit this file, `README.md`, Skill content, indexes, `docs/`, `conversation/`, `memory/`, or links as part of a version update.
