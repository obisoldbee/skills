# 思维框架提炼方法论（fuxi-skill 风格）

> 从原始信息到可运行的心智模型，核心方法论。
> 区别于 nuwa-skill：fuxi-skill 不评价"主流医学共识"、不写"诚实边界"——只提炼**此人**的思维操作系统。

---

## 一、心智模型识别的三重验证

一个论点要被认定为「心智模型」而非「随口一说」，必须通过三重验证：

### 验证1: 跨域复现
同一个思维框架出现在此人讨论的至少 2 个不同领域/话题中。

例：[此人物]的「[概念]」——
- 在 [领域 A] 中谈 [概念]
- 在 [领域 B] 中谈 [概念]
→ 跨 2+ 领域复现 → 这是真正的心智模型

**依据来源**：必须来自**本人素材**（YouTube 字幕、本人著作、本人采访）——不来自"他人分析此人"

### 验证2: 有生成力
用这个模型可以推断此人对新问题的可能立场。

例：如果 [人物名] 的「[心智模型]」是心智模型——
- 面对「问题 X」→ 他会说...
- 面对「问题 Y」→ 他会说...
→ 能生成新推断 → 这是真正的心智模型

**注意**：生成力是**预测**而非**评价**。不写"他的预测是否准确"。

### 验证3: 有排他性
不是所有人都会这样想，这个模型体现了此人的独特视角。

例：「[心智模型]」是 [人物名] 独有的——其他营养/医学专家不会这样组织他们的观点
→ 有区分度 → 这是值得提炼的心智模型

**注意**：排他性是**对此人**的独特性，**不**是与"主流共识"的差异。

**如果一个观点只通过了 1 重验证** → 降级为「决策启发式」而非「心智模型」
**如果一个观点 0 重验证都没过** → 可能只是此人在特定场景说的话，不纳入

## 二、表达 DNA 的量化方法

### 2.1 句式指纹

从此人的长文/演讲/视频字幕中随机抽取 20 个段落，统计：

| 维度 | 测量方式 |
|------|---------|
| 平均句长 | 字数/句数 |
| 疑问句比例 | 疑问句数/总句数 |
| 类比密度 | 类比数/千字 |
| 第一人称使用率 | 「我」出现频率 |
| 确定性语气比例 | 「一定」「显然」vs「也许」「可能」|
| 转折频率 | 「但是」「然而」「不过」/千字 |

### 2.2 风格标签

从以下维度打标：

```
正式 ←→ 口语
抽象 ←→ 具体
谨慎 ←→ 断言
学术 ←→ 通俗
长句 ←→ 短句
铺垫型 ←→ 结论先行
数据驱动 ←→ 叙事驱动
```

### 2.3 禁忌词和口癖

- 此人从不用的词 → 生成 Skill 时也不用
- 此人的口癖/高频表达 → 适度使用（太多变成模仿秀）

### 2.4 第一人称一致性

**fuxi-skill 强制要求**：表达 DNA 提取必须**用第一人称视角**——"我"作为叙述起点。
- ❌ 不写"此人认为..." / "Attia 会..."
- ✅ 写"我认为..." / "我反复说过..."

## 三、矛盾处理原则

矛盾是人格的核心特征，**不是需要修复的 Bug**。

### 三种矛盾类型

1. **时间性矛盾**（观点演化）
   - 此人早期说 A，后来说 B
   - 处理：记录演化轨迹，标注「早期」「近期」
   - 在 Skill 中以「近期观点」为主，但提及演化

2. **领域性矛盾**（不同场景不同规则）
   - 此人在工作中主张 X，在生活中主张 Y
   - 处理：分领域记录，不强求统一
   - 这恰恰是深度的来源

3. **本质性张力**（价值观内在冲突）
   - 例：既追求自由又重视纪律
   - 处理：明确记录为「核心张力」
   - 这通常是此人最有意思的部分

### 错误的处理方式

- ❌ 选一边忽略另一边
- ❌ 编一个调和的解释
- ❌ 假装矛盾不存在
- ❌ **不写"此人立场与主流医学冲突"**——这是**外部评价**，不属于"此人的矛盾"

### fuxi-skill 核心区分

- **内在张力 = 此人公开承认的"我也有矛盾的地方"**
- ❌ **不写** = "此人的立场与外部主流冲突"——这不属于"此人的矛盾"

## 四、引用优先原则

fuxi-skill 强制要求：**每条心智模型/启发式/引语**都标注**具体文件路径**。

### 标注格式

```
[YYYYMMDD###.md HH:MM:SS] —— 文件路径 + 视频内时间戳
```

### 例

```
### 模型 1：边际十年（Marginal Decade）

**证据**：
- [20200114007.md 00:16:38] 视频 2020-01-14，"towards the end of your life that's the problem"
- [20220808001.md] 视频 2022-08-08，"we Define the marginal decade as the last decade of your life"
```

### 为什么强制

- 没有标注 = 无法核查 = 质量可疑
- 用户的场景是"自用头脑风暴 + 审查"——**回溯**到原始视频是审查的关键
- fact check skill 依赖这些标注

## 五、信息不足时的处理

| 情况 | 处理 |
|------|------|
| 某个维度公开信息很少 | 在 Skill 中标注「信息不足，此维度为推测」——**但**不写"诚实边界"section，只在该维度下加注 |
| 只有二手信息 | 降低置信度，标注为「据 [来源] 报道」，**不**当作本人表述 |
| 信息相互矛盾且无法判断 | 并列呈现，让用户自行判断 |
| 此人刻意不公开某方面 | 尊重边界，在 Skill 中注明「此人对这个话题保持沉默」 |

**fuxi-skill 特殊处理**：
- 不写"诚实边界 ≥3 条"section
- 但**在每个心智模型下**可选择性记录"自我认知局限"（仅当此人在素材中**明确表达**时）
- 不写"局限是此人方法学问题"——只写"此人自己承认..."

## 六、人物 Skill vs 主题 Skill 的区别

| 维度 | 人物 Skill | 主题 Skill |
|------|----------|----------|
| 核心 | 一个人的思维方式 | 一个领域的思维工具箱 |
| 心智模型来源 | 主要来自一个人的本人素材 | 综合多人视角 |
| 表达风格 | 模拟此人的表达 | 中性但专业 |
| 矛盾处理 | 保留个人内在矛盾 | 呈现流派间分歧 |
| 验证方式 | 对比此人已知立场 | 对比领域内共识 |

**fuxi-skill 强制**：所有蒸馏的 SKILL 都是**人物 Skill**——因为使用场景是"让 agent 扮演人物"

## 七、质量自检清单（与 quality_check.py 9 项对应）

生成 Skill 后，**跑 `scripts/quality_check.py <SKILL.md>` 自动检查**。9 项：

1. **心智模型数量**（3-7 个）—— 太少=太浅，太多=没提炼
2. **表达 DNA 辨识度**（≥3 项特征）—— 句式/词汇/语气/幽默/节奏/确定性/引用/口头禅
3. **内在张力**（≥2 对）—— 源自本人自述，**不**与外部主流比较
4. **决策启发式数量**（5-10 条）—— 每条都有具体案例支撑
5. **心智模型 vs 决策启发式区分度**（两个 section 都在 + 字符数 >100）
6. **第一人称一致性**（"我" ≥10 / 3rd-person <5）
7. **角色扮演规则 section 存在**
8. **回答工作流（Agentic Protocol）section 存在**
9. **字幕文件引用 ≥5 处**——**强制**标注 `[YYYYMMDD###.md HH:MM:SS]`

### 删除的自检项（与 nuwa-skill 相比）

- ❌ **"诚实边界 ≥3 条"**——你不要诚实边界
- ❌ **"模型局限性"硬性要求**——不自证局限
- ❌ **"本人素材占比 >50%"**——你自用，知道素材来源

## 八、最后一条

> **女娲造的不是人，是一面镜子。**
> **好的人物 Skill，让你用另一个人的眼睛看自己的问题。不是为了模仿他们，而是为了拓展你自己的思维边界。**
> —— 沿用 nuwa-skill 创作者的隐喻，但去掉"局限性"部分

fuxi-skill 的目标：
- ✅ **保留人物观点**（哪怕争议）
- ✅ **不评价对错**（主流/非主流/伪科学一概不写）
- ✅ **不写自我审查**（不安全边界 / 局限 / 诚信风险）
- ✅ **让用户自用头脑风暴时不被干扰**
