# Computer Use 原生组件工作流

这是操作指引，不绑定具体项目或固定屏幕坐标。官方教程与当前界面不一致时，用当前可见菜单确认入口；不要猜消失的控件。

仅在选择 Computer Use 路线时读取。首次使用或从摘要恢复时，按当前工具要求读取运行时说明，再取得应用和状态。操作基于截图、指针、键盘和工具实际提供的可访问性信息，不假定拥有 Ego 的 DOM、Page 或脚本能力。Ego 任务读 [Ego 网页操作](ego-browser-workflow.md)，两路都执行 [内容规则](prototype-content-rules.md) 和 [共同验收](quality-and-recovery.md#原生备注的共同验收)。

## 只补原生备注

先按 [必要备注检查](prototype-content-rules.md#哪里必须补备注) 确定本次应补内容，再按 [备注布局与连线](annotation-layout.md) 选择目标附近的卡片位置、连接侧和检查项。保留已有页面及组件，先用截图和原生页面或图层清单记录旧内容。从当前工具栏定位原生备注入口，在授权位置添加一条，进入文字编辑并确认编辑区原文属于该备注，再用键盘输入。通过原生颜色控件选取指定样式，真实待确认文字用警示色及局部加粗。提交并退出文本编辑后移动卡片，再按需要调整端点；分别检查落点、位置、路径和吸附后的实际画面，避免统一排底部产生穿页长线。

没有 DOM 时，用可读截图、实际可访问性文本及原生图层逐条核对内容，不编造组件 ID 或颜色读取结果。删除前确认选区只包含本次撤回的备注。待保存指示完成后切换返回；必要时按当前应用允许的方式重新载入，再看受影响画面。只补备注不自动复制页面或增加交互逻辑。

上述备注步骤由原生操作原则和 Ego 实例整理，尚未对 Computer Use 的整条备注流程单独实跑。下方原有 macOS 组件经验也不能证明 Windows 快捷键或工具能力相同。新环境核对当前菜单和工具，先完成一处小编辑及读回，再扩展同类操作。

## 页面与复制

官方 [新建页面](https://modao.cc/hc/articles/331) 提供新建按钮、A 键和复制粘贴入口。Mac/Windows 的修饰键以当前菜单为准。本次 Mac 页面菜单显示 ⌘C/⌘V；页面左上角名称可选中整页。

先点击页面名，查看整页选区与属性，再复制。右键如果只出现粘贴等画布菜单，通常没有选中页面；重新读取当前选择。粘贴后查看新增页面列表和画面，重命名，再选中该页适应视图。页面快捷键 A 会受文本框焦点影响。

官方 [复制粘贴](https://modao.cc/hc/articles/412) 区分页面、组件以及粘贴时所选对象：页面通常向右寻找空白位置；组件的相对位置、原位置和左下位置取决于复制内容及当前选择。不要只按预想坐标判断复制成功。

复制后的元素可能重新判定归属。[图层归入页面](https://modao.cc/hc/articles/411) 说明鼠标拖动、键盘参数调整与图层移动的差别。画面半透明或内容被裁切时，先检查页面归属、裁切和坐标，不直接增加不透明度掩盖问题。

## 组件与图层

[编辑组件](https://modao.cc/hc/articles/333) 支持素材面板添加、图层列表选择、组合/打散、图层顺序和格式复制。被遮挡的元素可从图层列表选择，也可右键“选择图层”。组合内置顶只改变组合内层级，不能越过外层组合。

优先复用同页同类型组件。新矩形/文字可能继承上一次编辑的样式；显式检查填充、描边、透明度、圆角、字体、字号和对齐。仅把数值改成正确值而没有检查画面，可能仍留下错误层级或文本溢出。

模态状态先保留原页面，增加覆盖原页的遮罩，再放白色弹窗与弹窗内容。遮罩位于底板下方、页面内容上方；确认/取消与关闭图标在弹窗内。优先使用项目既有弹窗；需要自绘时，使用原生图形和文字。

## 文本、标题与输入框

嵌套文字的选择与编辑是两个状态。先选目标文本，进入编辑后再全选替换。检查文本编辑区出现且内容对应目标；未进入编辑时粘贴文字可能新建文本组件。编辑之后检查宽度、截断和换行。

项目有“标题”和“提示文字”时分别修改它们。属性面板顶端的组件类型名、图层名称、画面标题和输入框默认提示不是同一字段，不要用改名代替改标题。

[表单组件](https://modao.cc/hc/articles/338) 的单/多行输入框在外观栏修改默认提示词和颜色，单行输入可选键盘样式。文字式样例字段可能是一个由标题、说明与背景构成的组合；先确认具体结构，再编辑，不能凭外观假定它是可输入组件。

原生输入框在预览可输入是一项能力，不意味着本次需要设置输入、公式和键盘。静态“输入中”状态可用当前值、光标、焦点边框和原生矩形键盘表示。自动计算结果区沿用项目相应的颜色和外观，不声称已经配置运行时禁用；已有自动计算说明时不再加“只读”标签，见 [内容规则](prototype-content-rules.md)。

## 精确排版

选中组件后使用右侧 X/Y/W/H 调整。编辑数值、提交、退出焦点，再选下一个对象。先把组件做成可读完整状态，再调整间距。

[使用技巧](https://modao.cc/hc/articles/335) 介绍标尺、参考线、测距、空格拖动画布和撤销。页面整体缩放、组件几何居中和文字内容居中分别处理：按钮矩形居中不保证符号文字居中，文字水平居中也不保证垂直居中。

连续复制按键时，每次核对选中的是按键/文本，背景卡片尺寸应明显更大。源组件移动后，旧屏幕坐标已经失效；从当前图层或新的位置再选源组件。

## 本次 Mac 界面观察与官方说明的边界

| 操作 | 依据 | 使用方式 |
|---|---|---|
| ⌘C / ⌘V 复制粘贴 | 本次 Mac 页面菜单；官方 331/412 | 核对选中整页或组件后使用 |
| ⌘D 复制组件 | 本次组件操作成功 | 不能推广成页面列表复制方式 |
| ⌘1 适应画布 / ⌘2 缩放至选区 | 本次缩放菜单显示 | 新任务先查当前菜单；不依赖旧截图快捷键 |
| R 矩形 | 官方 341 和本次观察 | 先离开文字/属性编辑焦点 |
| Shift 多选 | 官方 333/335 | 核对选区与数量；工具的 AX 点击修饰键不必然等价于真实范围多选 |

以上是本次 macOS 墨刀原型编辑器的局部观察，不保证其他版本、系统或墨刀设计产品相同。
