# 检查与恢复

下表整理常见操作与验收问题。两条路线共用验收要求，但证据能力按实际工具区分。先依据当前界面验证问题是否适用，再选择恢复方式。

制作任务同时按 [制作阶段与独立质检](production-and-qa.md) 推进。制作人先自检，独立检查者再观察当前原型，负责人跟进修复与重检。检查以本阶段实际页面和业务要求为准，按覆盖范围判断阶段完成状态。

## 原生备注的共同验收

编辑原型或备注时，按 [发现问题必须处理](annotation-layout.md#发现问题必须处理) 覆盖受影响页面的新旧备注，再逐项执行 [布局与连线验收](annotation-layout.md#交付前逐项判断)。只核对落点不足以通过：卡片位置、连线路径与整个画布的碰撞分别检查。检查布局紧凑但不拥挤、引线不交叉且尽量短直；拥挤处先调整目标画布的页面排布释放空间，再核对卡片。空间充足仍有无必要折角、卡片过远、长线穿页、交叉或遮挡时，在授权内修正后再交付；不能只报保存成功。

制作前先完成 [必要备注检查](prototype-content-rules.md#哪里必须补备注)，交付前沿涉及的页面、操作和主要状态检查是否仍有遗漏，不能只检查已添加卡片。题面已写或不计分不构成省略理由；真实未决项明确保留。仅当任务包含考点制作时，另做考点范围检查。交付前用最新用户纠正再核一次。内容有依据、写入与计划一致、实际画面可用分别判断，不能以字数、颜色、保存成功证明业务要求成立。独立核对需求及当前原型，不能只验证同一份计划的抄写一致。

- 分别检查“需求已要求但原型漏画”“现有内容缺说明”“规则已知但旧稿相矛盾”“真实决策未定”。范围内可确定的问题必须修正。仅备注任务仍须修复备注本身的内容与布局缺陷；缺页、缺控件等超出备注范围的实现问题具体报告。用户当前明确禁止修改的对象保留未修状态，不给整个原型完整通过。
- 检查打点正文及相关状态的同一规则。新旧条款有明确覆盖关系时，按当前依据修订被覆盖部分，保留仍有效的内容；仅凭日期或颜色不能确认整卡失效。必要说明未读时，报告范围，不能宣称内容完整。
- 如果同时做考点，按 [考点边界](assessment-boundary.md) 分开报告原型补全与计分处置。没有关联考点的备注照常验收；从 rubric 删除已给信息后，核对对应原型说明没有被误删。评分文本不混入业务备注。

- 对照编辑前的原页面与旧备注清单，保护原始材料和未涉及的组件；授权修订的旧备注同步更新，不把“保护原文”误解成保留已被纠正的有效文案。核对本次新增、修改和撤回对象，不能只看总数。Ego 可用实际读出的组件标识辅助比对，Computer Use 用原生列表、可访问性信息和可读截图，不强求不存在的 ID。
- 按 [本期颜色定义](annotation-layout.md#本期改动的颜色) 核对新增、修改和撤回对象，保证用户能找到本期改动及具体差异；未改内容保持原色，待决提示不掩盖期次。原型写完或业务问题已确认都不能单独触发颜色归并。
- 查看每个受影响画布，逐条核对文字、用户指定颜色、尺寸及连线落点，确认没有遮挡、裁切或误改旧对象。DOM 字符串正确不能证明像素正确，也不能靠相邻画布推断。
- 观察真实保存状态，切换返回或在必要时重新载入一次，确认修改仍在。没有出现某个历史 tooltip 或 CSS 类名时，改查当前可见保存指示，不伪造成功。
- 使用验收脚本时，分别检查有效旧内容的保留、计划改动的正确性、发现的缺陷是否解决和整体布局。逐页检查卡片距离、引线和相邻页面布局。人工画面复核须实际完成并记录对应画面和结论，不能把复核字段预置为 `True`，或只检查截图文件存在就判通过。未检查记为未核实，发现缺陷记为未通过。
- 重新载入后若仅 z-index 等内部排序值变化，记录差异，再看文字、几何、颜色、连线及实际遮挡。不能把整段 style 字符串相等作为唯一通过条件，也不能忽略影响显示的层级变化。
- 原稿、纠正前计划和撤回截图保持历史身份。交付指出修改的是墨刀原型，列出实际数量和仍待处理内容，不含糊地写“已上线”。任务空间按所选工具的结束规则处置。

| 现象 | 应检查什么 | 恢复方式与完成条件 |
|---|---|---|
| 点击小图标后删除，整张字段卡片消失 | 选区是不是外层组合，名称和 W/H 是否属于图标 | 及时撤销；必要时从保留原页复制完整字段并恢复文案。进一步选中图标，确认小尺寸再删除。字段完整、仅目标图标消失 |
| 替换文字后又出现一条新文字 | 是否进入真正的文字编辑区域 | 清理本次新建的多余文字，选中内部文本并进入编辑。原组件的文本正确，无额外组件 |
| 内容正确但截断、挤压或换行 | 文本框宽度、对齐、字体与实际画面 | 调整 W/H 和位置，再查看标题/提示的完整渲染；不能只检查属性字符串 |
| 弹窗截图半透明，背后表格似乎穿透面板 | 当前是否仍在淡入、过渡或加载，面板和遮罩的最终状态 | 等待当前可观察的稳定状态，补看稳定画面后判断。确有样式问题再修；保存、稳定画面与所需预览分别核对 |
| 置顶/置底无效 | 当前对象是否处于组合内 | 检查外层层级；选择正确组合或图层入口调整。弹窗、遮罩和页面顺序正确 |
| 新按钮灰透明，或新图形被遮罩样式影响 | 样式继承、填充透明度、归属和层级 | 按原 UI 显式设样式；不要把页面外元素的半透明误当成组件透明度问题 |
| 按键出现大块底板、首键或底行不见 | 复制的源对象名称、尺寸和所在页；源是否已移动 | 清理本次多余底板，重新选真实按键复制。逐一看 1、0、小数点、退格及所有行列 |
| 运算符看着偏上，减号像破折号 | 真实字符、文字水平居中和垂直居中 | 根据参考统一字符。此案例采用 `+ - × / ( )`，ASCII `-`、`/`；逐一检查，不用 `—` 或 emoji `➗` 替代。新任务服从新参考 |
| 删除变量后仍显示“设置变量值：未设置” | 触发组件的交互面板与行为列表，复制页是否也带有行为 | 对本任务引入的行为打开编辑/操作入口，删除该行为，再检查它消失。变量列表为空不能证明动作清理完成 |
| 属性填错对象或索引点到其他字段 | 状态读取之后界面是否改变，索引是否过期，文本面板是否正确 | 重新读取当前界面，核对组件名与尺寸。不要复用旧 AX 索引或通过模糊标题匹配相似面板 |
| 首次点击无选择效果 | 应用是否激活、属性框是否仍在编辑、点击是否只完成失焦 | 重新读取状态，必要时再点击目标并检查选择。不能直接对未确认目标执行删除或批量修改 |
| 应用激活失败 | 窗口可见性、当前工具支持的应用/窗口动作 | 重新取得应用并检查窗口；只使用运行时已经暴露的窗口动作。恢复后重新读状态，不盲发快捷键 |

## 组件与流程修订的验收

- 矩形自身能满足文字和样式要求时，应是一个可编辑组件，不是矩形框叠加独立文字。仅有实际能力限制时保留组合并说明，不以视觉相似代替组件检查。

- 可编辑性核对真实原生元素和一次实际编辑/保存；逐项确认元素可单独编辑。复制后检查类型及文字，误贴图片及时撤回本次错误对象。
- 默认页签变化同时核对顺序、选中样式、实际显示内容及相关预览/弹窗，不只改标题。字段重排同时核对表头、每行值、边框和说明。
- 新增或本次整理的页面名称要能识别业务和状态，核对页名、画布名与内容标题；保留有意义的差异，不把 Copy 或旧表单名当业务依据，不顺带全量重命名。
- 合并流程时同步入口、页名、按钮、备注目标与废弃中间状态；保留用户现场修订。只修改当前范围，不借机全量重构。
- 固定比例与不溢出分别验证；弹窗父框、内容区、说明、操作区和保存按钮均需完整可见。文字的垂直/水平对齐与外框位置分别看。
- 需要打印设计时，在字体/图片就绪后按本项目实际数据与约定极值检查换行、分页和签名避让；屏幕缩放、打印缩放分别处理，不照搬其他项目的比例、数量或尺寸。普通页面和打印模板可能有不同的字段格式，逐视图核对。

检查分两层：整体看原稿、新页、设备分组和流程顺序；关键页按可读比例看标题、符号、校验、键盘及弹窗。每个状态都需要看画面，不能从相邻页面推断。

流程图还需执行 [逐页检查与修订](flowchart-design.md#逐页检查与修订)，分别核对业务条件、原生连接、实际画面和本次要求的预览路径。检查人员可按 [Ego 协作方式](ego-browser-workflow.md#绑定已有页面) 独立观察；同一原型保持一个编辑者。

## 保存与导出一致性

本节仅在任务要求导出或打包时执行。先提交文字、拖动和属性编辑，等待当前界面的真实保存状态，再切换返回，必要时重新载入一次；核对的是修改后的文字、端点、路径和页面尺寸，不能只看保存图标或仍在内存中的截图。

- 从确认后的原生页面导出，核对页名、范围、数量、尺寸、裁切和实际内容。重新打开最终文件，按可读比例查看改动区域及相关布局，特别检查箭头端点、标签和页面边界。
- 编辑器显示新线条、导出文件仍为旧线条时，先保留差异，复查是否已提交和保存、是否导出正确页面及最新下载；找出原因并重新导出，不能只沿用较早的 PASS。
- 图中绑定批注的全文可能不随静态图片导出。先检查实际输出；交付要求包含完整说明时，通过支持的原生导出方式或本次配套说明补齐，并核对可定位关系，不把正文丢在只有编号的图片里。
- 需要将透明 PNG 转 JPG 时，显式合成约定底色并保持清晰度，检查转换后的文件。原生导出、转换文件和压缩包分别核对；按当前约定的文件与格式检查实际包内清单，剔除打包时附带的系统元数据及无关旧稿，不改原始资料。打包后解出或直接比对成员字节，确认使用最终文件，保留所需来源。
- 最后一次修订后，重验受影响页面、交互和导出，并更新最终文件清单或已有验收记录中的对应结果及哈希。旧报告保留为历史版本；只更新受影响证据，范围外已通过的检查无需反复重跑。

本次重点失误是“确认选择”不足：扫描图标、字段背景、文字和键盘底板都曾被误选。名称、选区及 W/H 是删除/修改前最有用的交叉检查，不是只为留证而做的形式步骤。
