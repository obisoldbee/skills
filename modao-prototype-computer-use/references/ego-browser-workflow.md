# Ego 网页操作

仅在选择 Ego 路线时读取。先读当前安装的 `ego-browser` Skill，使用它实际暴露的 TaskSpace、Page、鼠标和键盘方法。本文不替代其控制权、错误恢复及结束规则，不要求安装工具或启动新的浏览器。API 签名以当前 Skill 和运行时帮助为准。

## 绑定已有页面

按当前任务恢复同一个 TaskSpace 和 Page，核对墨刀文件、画布与页面内容。已有 Space 编号只在本次任务中使用，不从案例复制。对用户控制、inactive/unassigned 或权限提示，按 Ego 规则停下；不新建 Space、改用 Computer Use 或后台请求绕过。只有当前授权覆盖时才接管。内容审查可以独立继续。

同一文件只有一个编辑者。其他执行者可做本地内容核查；当前授权及 Ego 运行时允许独立质检空间时，可在另一个 Space 只读查看同一原型或预览，不共用编辑者的活动 Page，不写同一原型。新建空间、接管和保留规则仍按当前运行时执行。检查绑定的版本，修复由编辑者完成后交回质检。观察取决于下一步需要什么，普通菜单先用当前 snapshot 和可辨认的控件；画布、富文本和连线缺少语义时使用截图与鼠标键盘。

## 多文件调研与目标核对

多文件任务先看当前标签页归属和受管额度，只接管本轮需要的页；需要轮换时按当前 Ego 合同释放已读页，保护用户或来源未知的原标签页，不为腾额度关闭它们。具体额度和 API 以当前运行时为准。

点击画布后，核对选中画布和内容属于目标，再开始采集。目标原已选中时直接核对内容，无需等页面列表发生变化。切换未生效时重新检查当前可点击名称、遮挡和浮层，不反复点击相同外层行。标识从当前观察复制，不手写猜测；特殊参数查运行时帮助，不把 CSS 选择器当成 snapshot 节点引用。

读取既有批注时同时检查卡片和打点。通过当前原生入口展开打点正文，核对浮层属于目标再读取；未展开或不可读标为未读，不能计为空备注。浮层遮住下一目标时先关闭，再观察并操作。当前 DOM 的类型、类名和编号只用于本轮定位，不固化成跨版本接口。

调研只证明已观察范围。结构计数、可读截图和预览实测分别报告；同一对象重复采样需去重并保留观察时间，前后变化单独说明。采集失败的目标不算已读，也不据此判定页面没有相关设计。更完整的缺口判断见 [内容规则](prototype-content-rules.md#先读全相关说明)。

## 读取与编辑原生备注

1. 先按 [必要备注检查](prototype-content-rules.md#哪里必须补备注) 确定本次应补内容，再读 [备注布局与连线](annotation-layout.md)，根据目标和四侧空间安排卡片，不能把所有卡片集中到底部再用长线穿页。编辑前保留原页面和备注清单。可通过 `page.evaluate()` 读取当前渲染 DOM 中的正文、组件标识、颜色和位置，用来比对旧内容与新计划。只读取页面可见界面的表示，不遍历应用内部状态，也不通过脚本改 DOM、状态仓库或私有 API 写原型。DOM 不足时用截图及原生图层信息核查。
2. 从当前界面定位原生卡片批注入口，先做一条小备注验证。双击进入正文编辑，核对选中的备注与编辑区原文后再替换。富文本编辑区可能在独立浮层中，不能假定它是备注节点的子节点。输入使用 Ego 当前支持的原生控件动作和键盘方法。
3. 使用原生颜色面板应用 [本期颜色定义](annotation-layout.md#本期改动的颜色)，未改内容保留原色。真实待确认内容用局部警示和加粗；确认后去掉待决标识，保留本期颜色到收尾。检查实际画面。颜色数值读回可辅助核对。本期颜色由当前任务确定，不套用历史任务的固定色值。
4. 提交并退出文字编辑后，先把卡片移动到目标附近，再按需要调整连线端点。分别检查落点、卡片位置和路径；移动后的吸附与端点保留必须逐条回读，不假定标题栏拖动一定保留端点。首次拖动无效先检查焦点、选区及端点，不能连续盲拖。撤回备注时通过原生菜单只删除本次指定对象，再核对其余备注。
5. 平移前确认当前手型工具及选区。改变缩放可能退出手型；DOM 中存在 `handMode` 类名不能证明工具已激活。一次拖动若只改变选择，重新读界面，不把它当成视野移动。
6. 等实际保存指示完成，必要时做一次重新载入和受影响画布读回，随后按 [共同验收](quality-and-recovery.md#原生备注的共同验收) 核查。不要在完成后反复刷新同一结果。

本次可读的备注节点使用 `.wSticky` 与 `data-cid`，保存图标曾从 `is-saving` 变为 `is-success`。这些是历史观察，新任务必须先在当前 DOM 中确认。按当前节点属性定位备注，并读回保存状态。

流程图端点、标签和节点手柄可能靠得很近。拖动前用当前选区和截图辨认目标，操作后读回实际路径及标签位置。端点暂时对齐时先提交操作并等待真实保存，再切换返回或必要时刷新核对；新改动尚未保存时不要用刷新当作验证。导出不一致时按 [保存与导出一致性](quality-and-recovery.md#保存与导出一致性) 排查。

## 结束本次操作

按当前 Ego Skill 处理成功结束和任务空间释放。成功时执行规定的 `finish` 并等待回执；仅按其保留例外留下必要结果页，保护用户创建或来源未知的标签页。用户接管或错误停止时遵守对应的 handOff/停止规则，不把错误当成功结束。旧案例中 Space 仍开着不构成新任务的保留授权。

交付写明墨刀文件和修改内容、保存读回与像素检查结果、任务空间处置。Windows 上先验证一处编辑和保存，再扩展。
