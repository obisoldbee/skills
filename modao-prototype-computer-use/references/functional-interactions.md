# 交互、变量与预览

仅在当前用户明确要求可运行预览或运算时使用。先确认画面状态，选择够用的原生行为；静态任务不进入运行时配置流程，但仍按 [原型内容规则](prototype-content-rules.md#先判断原型要补什么再判断能不能考) 补齐公式口径、输入输出、状态变化等说明；不得把不配置交互理解成不描述交互。

## 页面跳转与弹窗

依次读取 [添加交互事件](https://modao.cc/hc/articles/334)、[交互触发及行为](https://modao.cc/hc/articles/469) 和所需的 [页面交互](https://modao.cc/hc/articles/353)。在界面中选择真实触发组件，添加对应触发方式、行为和目标；必要时设置返回、关闭或显示/隐藏。

将用户需要的路径写成“来源页/组件 → 动作 → 目标状态”。复制页面之后重新检查目标绑定，避免全部副本仍指向旧页。多步骤行为核对顺序。整体跳转与动态组件内部状态切换不是同一对象。

流程图跨页入口写明目标业务和接续动作。同一目标页承接不同来源时，分别核对到达后应继续的位置及状态；多个来源共用的异常处理页，返回时接回真实来源和同一次业务事件。需要动态返回时使用当前原生能力，不把所有入口都绑定到同一固定返回页。是否保留数据仍按已有业务依据处理。

浮层或内部状态可参考 [浮层组件](https://modao.cc/hc/articles/441) 与 [动态组件](https://modao.cc/hc/articles/398)，但以当前项目结构和用户需要为准，不为了使用功能重做整套 UI。

## 公式与变量

读取 [变量](https://modao.cc/hc/articles/464)、[表达式](https://modao.cc/hc/articles/465)。先绑定输入组件/变量、计算触发、缺值和非法值处理、结果组件及格式。标签“单价”不是数值来源。

先用界面核对变量类型和当前表达式入口，再设置。数值、文本、表达式模式等具体控件必须由当前界面确认，不能把教程字符串直接粘贴进未经确认的字段。可将 [购物车计价示例](https://modao.cc/hc/articles/468) 作为功能说明；该篇视频二进制未收录，保留原链接和封面。

正常值、零、缺值和本任务涉及的边界值分别验证；如果组件能力或输入来源不足，说明实际限制，完成可独立的页面工作。不能把示例 `32.00 × 20 = 640.00` 的静态文本视为运算测试。

## 预览与清理

用 [预览](https://modao.cc/hc/articles/347) 或 [快速预览](https://modao.cc/hc/articles/413) 实际点击、输入并检查预期状态。只报告走过的路径和测试值。

新增或改变跳转后，从各个适用来源分别测试进入和返回，核对实际目标及接续位置。页面加高、加宽后，在实际演示尺寸下检查底部、侧边节点和返回入口都能到达，按需要配置纵向或横向溢出滚动。滚轮落在批注或内部滚动区域时，先移到页面空白边距再试并核对真实滚动位置，区分滚轮被截获与页面裁切。编辑器能看全仍需另查预览。

用户将需求改为静态页面时，删除本任务引入的配置。先删除触发组件上的动作，再按需要清理变量/表达式；检查由这些页面复制出的各个状态。动作列表中的“未设置”需要单独处理。检查触发分组中的实际行为条目，空分组可保留。
