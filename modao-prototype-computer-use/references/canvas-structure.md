# 功能、画布与状态页

在同一个原型文件内，用左侧文件夹回答“功能在哪”，用画布名回答“这次要办什么事”，用页名回答“现在进行到哪一步”。先选一个代表性功能，确认目录和第一张交付图好读，再排其余功能。

## 什么时候另开一张画布

| 遇到的情况 | 怎样组织 |
|---|---|
| 同一操作者在办同一件事，变化只影响这次操作 | 留在一个画布。初始、输入出错、提交成功等状态按实际需要取舍；一个简单弹窗通常跟着触发它的页面 |
| 分支有独立入口或产出，换人处理，或可以单独验收 | 按动作和对象另开画布。与原功能平级就放同层；只能从父功能进入且能独立验收时，父画布留本层，子画布放到父功能的下一层文件夹。一个保存提示、一个弹窗等同任务状态留在原画布 |
| 多处抵达同一功能 | 保留一份目标画布，各入口注明目标画布、起始状态和返回位置。各来源有不同回退行为时分别说明 |
| 同一张表单衍生很多近似截图 | 按改变的业务结果合并等价状态。独立的打印、同步、权限配置各自归位；对数据组合用一条有依据的文字框说明，需看视觉差异的状态仍画出来 |

文件夹通常用两三层便能定位，例如“期次／业务域／有子功能的父功能”。沿用已有期次或模块结构，只有分组能帮助查找才加一层。[画布相关问题](https://modao.cc/hc/articles/370)写明最多七级。2026-11-10 在原型编辑器的新副本实测，从根目录下第一个文件夹算第 1 级，6 层文件夹下可以放第 7 级画布，刷新后仍可进入。第 7 级也可建为文件夹，此时“子画布”和“子文件夹”均不可选。需要容纳画布的分支最多排 6 层文件夹。操作入口见[编辑画布](https://modao.cc/hc/articles/361)。

例如，订单列表和编辑订单各占一个画布，编辑明细放在下一层。

```text
二期需求／订单                         文件夹
  订单列表                           画布
  编辑订单                           画布（打开编辑、修改待保存、已保存）
  编辑明细                           文件夹
    多值处理                         画布（保留一项、清空待处理）
  同步订单                           画布（首次同步、再次同步）
  打印订单                           画布（预览、打印结果）
```

## 画布怎样排

先排主路径，入口在左上，沿同一方向读；错误、取消等分支放在触发状态下方。两三个短状态可以同排，四个状态可排成两行。每个状态连同四侧备注一起占位，先留出文字框的位置再排邻页。常用起点是每画布 1 至 4 个状态；到第 5 个就检查能否按功能拆开。这些数字是排版建议。一个不可分的短流程仍可保留，多页并排造成读图困难时应提前拆。

保留相关状态的邻接关系。若不能说出某一页与前后页的触发动作，或读者必须来回横拖才能找到同一条线的两端，先重排或拆出子功能。导出时整体图帮助定位，详细图需要在接收端常用宽度读清条件、数字和最小的文字框；只提高倍数常常解不了一张长图被整体缩小的问题。

共享页尽量放在两个真实来源之间。例如列表和搜索结果都能打开订单详情，可以把两种来源左右排，详情放在两者下方居中。按备注和引线所占的实际空间调整位置。分别从列表和搜索结果进入，关闭后核对原列表位置，以及原搜索条件和选中记录。用户指定保留现有画布时，只调整授权范围内的页位与相关备注，重排后再从两个入口各走一遍。

## 整理已有长画布

先记下授权范围内的旧页名、实际内容、入口及返回目标。按“旧页 → 新文件夹／画布／状态”逐项对照，在副本上先移一个完整功能；原稿有打点时先展开读取。重名页、复制残留名用界面标题辨认。保留有意义的状态、已有交互及仍有效的备注。

复制整页前，沿控件把页外备注也列进去。放到新画布后，逐项从目标控件回找对应文字框和引线。页外说明可能留在原画布；缺的有效规则按原对象在副本补回。旧稿里仅供制作人使用的施工标记留在原稿。

切回目录再进去，核对父子位置、同级顺序、页面清单及文字框归属。整理已有可点击原型时，从原入口走到新位置再返回，尤其检查复制后仍指向旧页的事件。真实界面能选到跨画布目标才配置跳转。若必要的跨画布往返在当前编辑器无法实现，可把必须连续演示的状态保留在同一画布，并在目录中清楚命名。静态交付直接在入口写明目标画布和页名。
