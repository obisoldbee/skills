# 原空间收尾

`run_checkin.py` 的一次浏览器调用创建并负责一个空间。创建后立即保存 `spaceId`；所有页面动作、积分读取和收尾都在该空间内进行。

- 正常新签到、原已签到、正常查询、确认维护：调用一次 `task.finish({keep:[]})`，等待结果，再只读检查原数字 ID。`finish` 返回 `closedSpace: true` 后列表可能短暂滞后，允许最多约 3 秒轮询；不重新调用 finish，也不新建空间。
- 只有 `closedSpace: true` 且原 ID 已消失，才是“已关闭”。残留、列表错误或超时是关闭未确认。其他历史空间即使同名也不属于本轮，不关闭它们，也不据此误报本轮失败。
- 登录、控件、网络或积分核验仍有问题时，在仍有控制权的原空间 `handOff()`，核验交接并给出原 ID。用户已接管时停止，不重新认领或关闭。
- 关闭失败保留业务结果，在本轮报告和回执中记录清理异常，不单独向用户发送“签到需处理”飞书；清理责任仍属于执行器，不转给用户。不得重复签到或另建空间做验证。通知和报告属于同一执行器，不由模型补写。

进程硬中断的回执可能只有部分事实；后续调用只能显示待核查。人工修复先只读定位原空间和已尝试动作，不因缺失记录推断未签到或新开空间。
