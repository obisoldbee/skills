# 新号准备

## 领取与装备

先检查任务、活动和邮件中达成的免费项。逐项读对象、按钮和代价，确认领取后按钮变灰、出现奖励弹窗或对应余额变化。批量领取前确认范围覆盖的是已达到条件的免费项。活动是否还在、按钮可否领，以当前界面为准。

| 入口 | 新号截图显示 |
| --- | --- |
| 英雄之旅 → 挑战 → Lv.1 | 已完成「进行1次英雄召唤」和「队伍等级达到3级」，两项显示「领取」。「拥有5个12级英雄」显示「前往」，进度 0/5。 |
| 英雄之旅 → 礼包 | 「新晋成长礼包Lv.1」标为免费，同页也有带红点的付费礼包。 |

| 公告与活动 → 历战的荣誉 | 5 级、10 级均显示「领取奖励」，各含 50 圣魔晶，10 级另有武器。 |
| 永焰锻炉 | 免费档「薪焰之助」1 级奖励已亮，同页有「一键领取」以及另一个 ¥128 解锁档「煌炎之灵」。 |

回到「英雄 → 单名英雄 → 装备」，对本场出战英雄使用「一键装备」。逐人读回武器、防具、头饰和饰品，遇到空位就查背包和对应部位，再决定补装。若界面要求转移已占用装备，先对照其他出战者的配置。马修、兰斯的截图都显示有一键入口且各空三个槽，马修已装长剑，兰斯已装头盔。截图显示的是入口和待处理状态，领取与一键配装结果需要操作后验证。

## 节省推图操作

- 可见 SKIP 时跳过剧情，有跳过确认框就确认。历史新号 5 级解锁倍速，6 级时实际切到 ×3，10 级时实际关了战斗动画。按账号界面解锁状态调整。
- 从「玩家信息 → 设置 → 战斗设定」或「战场信息 → 设置 → 战斗设定」查看动画和效果。按用户要求关我方、敌方单位特效和触发表现，关闭战斗动画后回战斗地图核对「×3」「动画关」，再以一次交战是否留在地图视角确认生效。
- 推图积累的任务在「任务 → 每日」有奖励。历史新号在商队事件后用一键领取收午餐、晚餐和地图事件奖励，队伍从 3 级到 6 级，领取的 3 个汉堡当时未使用。另一次手领「解决 1 次地图上的事件」从 9 级升到 10 级，界面显示恢复 20 体力。
- 若玩家要留券、留晶，就用已有英雄和约定的免费召唤。出现 100 圣魔晶回溯、标价补体力或付费解锁就取消。用已有体力按用户目标推进，低于上限后利用自然恢复。其他账号按当前授权和任务目标处理，回读兑换或消耗后的余额。

## 连续拖动的实测边界

MuMu 中兰斯上阵成功时，ADB 的 `input swipe` 向安卓直接发送了 950 毫秒的连续触控。候补兰斯进入绿色空位，参战人数从 4/5 到 5/5，战力从 944 到 1,200。之后用电脑插件的窗口拖动尝试对调 MuMu 已上阵英雄，两人仍在原位。带「强制上阵」标记时先看当关限制。

在向日葵窗口里调用电脑插件拖动，尝试的是把候补拖进空位，人数没有变化。同一远控会话中，普通 Windows 设置窗口标题栏也未拖动。两个窗口测试的游戏动作不同，现有证据还无法确定拖动链路中哪一步失效。
