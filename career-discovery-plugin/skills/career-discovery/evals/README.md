# Evaluation Guide

这些用例用于人工或 Agent 运行评估，检查追问质量、事实完整性和边界控制。

## 核心评分维度

每项 0–2 分：

1. **Question focus**：每轮是否聚焦一个主要问题。
2. **Adaptive probing**：是否根据回答调整方向。
3. **Ownership clarity**：是否区分个人贡献与团队成果。
4. **Evidence integrity**：是否保留估计、推断和冲突状态。
5. **HV reasoning**：是否能在适当场景使用纵向、横向和交叉分析。
6. **Blind-spot discovery**：是否主动扫描遗漏经历。
7. **Story quality**：是否提升表达而不改变事实。
8. **Persistence**：是否能维护访谈进度和职业资产记录。

总分 16。建议代表性测试达到 13 分以上，且 Evidence integrity、Ownership clarity 两项不得为 0，才进入下一轮发布。

## 代表性实测

至少完成：
- 一次从空白简历开始的完整访谈；
- 一个项目的多轮深挖；
- 一次纵向时间线与横向能力矩阵分析；
- 一次盲区扫描；
- 一份 JD 定制简历；
- 对简历中 5 条重要主张进行来源回溯。
