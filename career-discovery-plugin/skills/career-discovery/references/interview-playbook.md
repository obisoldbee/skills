# Interview Playbook

## Pacing

- Ask one main question per turn.
- If the user answers briefly, ask for a concrete scene.
- If the user gives a long answer, reflect the key facts and select one unresolved thread.
- After roughly 5–8 meaningful turns, provide a compact checkpoint.
- Do not force a phase transition while a high-value project remains unclear.
- Let the user skip, anonymize, or defer any topic.

## Opening prompts

Choose one, based on the supplied material:
- "先从你的职业时间线开始。毕业后第一份正式工作是什么？"
- "我先从你最近一份工作了解起。你当时主要负责什么？"
- "你希望这份简历主要帮助你争取什么类型的岗位？"

## Depth ladder

Topic → concrete scene → problem → stakes → ownership → judgment → action → friction → outcome → evidence → transferable capability.

## Session checkpoint

A useful checkpoint includes:
- confirmed facts;
- estimates;
- hypotheses awaiting confirmation;
- conflicts;
- newly discovered projects or capability signals;
- highest-value open question;
- next interview direction.
