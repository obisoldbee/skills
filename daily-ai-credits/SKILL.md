# 每日领取 AI 应用积分

默认检查 WorkBuddy、TRAE CN、Qoder CN、豆包工作和 ZCode；用户限定应用或账号时遵循限定范围。执行每日领取任务时，按下述流程领取并更新。用户仅要求查询时，只观察授权范围内的状态，不领取、更新或切换未授权账号。通过当前可用的电脑操作工具与应用界面交互，以本次可见状态为准。

## 执行顺序

1. 打开任何应用前，按下列 bundle ID 记录本次范围内每个应用是否正在运行；打开豆包工作后、切换前记录其原来的当前账号。若不能可靠判断某个应用的初始运行状态，标为未知，结束时不要主动退出它。注意「豆包工作」和「豆包」是不同应用，不要用后者代替。
2. 按下方入口逐个处理签到或活动。记录每个应用或账号的本次新增数量、领取结果和最新余额；可刷新时刷新余额。领取按钮、宣传数量和点击动作都不是到账凭据，以成功提示、已领取状态或领取前后变化为准。用户指定账号时先核对当前标识，无法匹配则停止该账号的领取并报告。
3. 全部领取检查结束后，逐个检查并安装本次范围内应用的官方内置更新。若显示可下载、安装或重启完成更新，按界面操作；更新后重新打开并核对版本或更新状态。当前有正在执行的任务、未保存内容或更新需要额外权限、协议时，保留现场并报告具体阻塞。更新失败不抹去已确认的领取结果。
4. 尽力切回豆包工作原账号。按开始时的运行状态收尾：原本运行的应用保持运行，更新重启后未自动恢复的重新打开；原本未运行、由本次任务启动的应用正常退出，核实确已退出。任务期间用户另行打开或开始使用的应用保留运行。无论单项失败或需要人工处理，都继续处理其他应用和安全收尾，并报告未恢复的项目。
5. 用下方四列表格汇报，并另用简短一行报告各应用更新结果及未完成的状态恢复。

## 领取入口

- **WorkBuddy**（`com.tencent.workbuddy.mac`）：侧栏「Buddy加油站」；若未显示，从用户菜单进入。点击「立即领取」，等待「领取成功」。用户菜单中的「积分余额」可刷新后读取。
- **TRAE CN**（`cn.trae.app`）：左下角用户菜单 →「签到」，确认「已签到」，记录可见余额和变化。
- **Qoder CN**（`com.qodercn.app`）：用户菜单 →「权益中心」→「每天领 100 Credits」→「领取」，确认「领取成功，Credits 已到账」或当前周期「已领取」。在「我的用量」刷新并读取可用 Credits，区分套餐和资源包。活动曾显示每天北京时间 10:00 刷新、领取后 30 天有效；跨日残留的活动窗口须先关闭重开。10:00 前若重新打开后仍显示「已领取」，报告本周期已领及下一次刷新时间，不声称新周期奖励已到账。
- **豆包工作**（`com.work.pc.doubao`，本机可用 `/Applications/DoubaoWork.app` 消除同 bundle ID 的路径歧义）：记录左下角当前账号，侧栏签到卡片 →「立即签到」，核实「签到成功」及当次卡片额度。打开账号菜单，检查主列表和「更多账号」中的已登录账号，逐个切换并确认账号标识，分别检查并签到；每个账号单独记录结果及可见的可用额度。无签到入口时如实报告；需要登录、验证或无法切换时记录具体阻塞，继续其他账号。完成后切回原账号并核实。不要添加账号或退出登录。
- **ZCode**（`dev.zcode.app`）：查看左下角活动卡片，辅助功能树未显示时查看截图。活动存在且可领取时点击「领取」，确认领取成功并记录实际 Token 数量、适用模型、生效时间和有效期；活动不存在或状态不明时如实报告。宣传数量不等同于已确认领取，也不等同于账户余额。

## 更新入口

- WorkBuddy：用户菜单 →「检查更新」。
- TRAE CN：macOS 应用菜单 →「检查更新」。
- Qoder CN：侧栏更新状态或应用菜单；出现「安装更新」时按提示安装并重启。
- 豆包工作：用户菜单 →「检查更新」或「完成更新」。
- ZCode：应用内更新提示 → 更新窗口 →「重启以更新」。

以当次实际界面为准；更新后核对已是最新版、版本号或其他完成提示，只有下载中、安装中或点击操作时标为未完成。不要参与抽奖、邀请、购买或其他活动。

## 汇报格式

使用四列：`App | 新增情况 | 余额 / 有效期 | 打卡结果`。豆包工作每个账号单独一行；ZCode 第二列写已确认领取的 Token 和模型，第三列写生效时间及有效期。不可见或无法核实的数字写「未显示」或「未确认」，不根据旧记录推测；未在本次新增则写「本次无新增」或「未确认」，不把历史领取写成本次新增。

结果列用 ✅ 表示已确认领取成功或本周期已领取，🟡 表示无入口、未到刷新或结果未确认，❌ 表示登录、切换或操作失败；同时附简短文字说明。表格后简报各应用更新状态和账号、应用运行状态恢复情况。若定时触发环境要求固定外层格式，把表格及更新简报放入该格式的消息内容中。
