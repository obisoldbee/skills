# WireGuard 多端分流

## 绑定本次任务

按当前请求选择服务器核查、文件生成或已授权修复，可以单独执行其中一项。仅生成文件时，使用已确认的服务器绑定和规则快照；缺少服务器访问条件不会阻止独立的离线生成。说明与报告使用用户当前语言，命令、字段和原始证据保持原样。

先读项目已有的现场连接和测试指引，再从当前及前文用户指令确定下列适用信息。已明确的范围直接沿用；缺项标为 unknown，只补阻塞当前步骤的字段。只研究交付结论与方案，只生成文件完成离线合同；这两类任务无需补做现场验收。

- 操作效果是研究、只读核查、生成文件，还是已授权修复/应用。绑定实际执行主机、目标设备、用户既有代理入口和需保留的工作连接，沿用已获准动作；保留既有实例、静态 IP、服务端和设备密钥。
- 生成或应用配置时，`targets` 必须显式列出本次所有设备，取值为 `iphone`、`android`、`windows`、`macos`。用户要求“四端”时四项齐全，不能用桌面端代表 Android。
- 云账号、profile、区域、实例 ARN/名称、接口名、服务端公钥、端点与核对时间；每设备的独立隧道 IPv4、原始配置路径和 peer 角色（正式或测试）。真实现场值留项目私密记录。现场测试还需核对身份占用、时钟偏差、物理出口和共享带宽时间窗，见验证合同。
- 用户授权的私密输出目录，目录 0700、文件 0600。含私钥文件只写入该目录。Skill、仓库和普通交付包只放脱敏代码、说明和回执。
- 国内域名、IPv4 网段的完整快照路径、获取日期、来源、归一化后数量，以及现有 DIRECT 例外。缺完整规则时保留缺口，不能用几个示例域名交付“完整配置”。
- 分设备记录 App、协议、主导入文件、壳/core 版本、core 哈希与构建标签、活动配置哈希、合并脚本、VPN/TUN、DNS 和 IPv6 状态。区分已采用版本、候选及替代关系；活动版本未读回时记 unknown。没有设备访问条件时保留 `pending_target_device`。

输入 `client_configs`、`cn_domains`、`cn_networks`、`custom_direct_rules` 只读；生成器只写 manifest 绑定的 `output_dir`。服务器和当前客户端的应用操作按用户本次授权另行执行，生成步骤不隐含应用授权。

## 运行条件

本 Skill 无固定设备或网络绑定。离线生成使用 Python 3.10+、POSIX 主机和支持 POSIX 权限的私密文件系统，网络可离线；可在该主机生成四端文件。生成器在原生 Windows 上会停止，Windows 客户端配置应在合适的生成主机准备后私密传送到设备。

服务器核查需要本次授权目标的实际访问条件；客户端应用与验收需要对应设备和客户端版本。先核对当前主机、输出目录权限及目标绑定，缺少哪项就保留哪项待验收，继续可独立完成的部分。

## 执行顺序

1. 请求涉及服务器核查或修复时，按 [服务器核查与修复](references/server.md) 读取实际运行与持久配置，记录时间与结果。只读核查不要读取服务端私钥或执行重启。
2. 请求涉及文件生成时，按 [生成输入合同](references/generation.md) 准备私密 JSON manifest，再执行下面的生成与验证步骤。原始配置只读；IPv6 选择统一为 `ipv4-only`。该生成器不处理双栈方案。
3. 需要生成文件时运行下面的生成器。它在写入前验证所有目标，目标映射缺项、重复地址/私钥、混用服务器或规则数量不符时停止。它不调用网络，不修改服务器，不生成密钥。

```sh
python3 scripts/build_clients.py --manifest /absolute/private/input-manifest.json
```

4. 涉及文件交付或应用时，按 [各客户端操作](references/clients.md) 补充本次实际导入说明。Android 使用独立原密钥，CMFA 自己管理 VPN，不加入桌面 `tun`、网卡名或进程例外。
5. 按 [验证与交付](references/validation.md) 选择本次范围内的语法、实际路由、故障、目标设备及完整传输/稳定性检查，只重跑受影响项。测试副本、端口、进程和 peer 身份分别隔离；独立测试身份涉及服务器写入时沿用对应授权，只读检查保留只读。

## 完成条件

涉及文件生成或应用时，按 `targets` 逐台列出 App/协议、主导入文件、IPv4 参数参考副本、文件哈希、规则数量/覆盖和验证状态。iPhone 还交付手工节点字段。整批说明写明实际路径、客户端步骤、版本状态与替代关系。纯研究或只读核查交对应报告。

分列生成、目标核心解析、隔离路由、目标 App/VPN、完整传输及约定稳定性。每项使用 passed/failed/pending/inconclusive/not_requested，并绑定配置哈希、实际版本、方法、时间窗和证据。仅在本次请求所需项目满足后报告修复完成；短时连通只交该项结果。服务器变更回读运行态与持久状态。已授权修复继续推进，范围外动作只暂停受影响部分。

默认海外策略组只含 WireGuard 节点。国内域名和 IP、已有 DIRECT 例外走直连；WireGuard 故障时海外请求失败，国内仍可连接。IPv6 顶层开关、DNS 开关、原始 AllowedIPs 和应用 VPN 设置需一起核对，尤其保留用户已验证的本地 IPv6 修复。
